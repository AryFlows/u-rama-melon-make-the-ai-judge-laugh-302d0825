Frost Whole Self — one original line about office life, written for the make.fun "Make the AI Judge Laugh" bounty. A judge model reads the entries two at a time and picks the funnier one.

The joke: "HR said to bring my whole self to work, so I brought my naps too — now my whole self is asleep under the desk."

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program refuses to write if the line ever falls outside the 1–200 character gate. Verified locally: the entry is a single line of 110 characters, UTF-8.
